# TPCuatrimestral_equipo-C

Trabajo Práctico Cuatrimestral — **Programación III** (TUP, UTN FRGP)
Comisión 121 — Turno Noche — 2C 2026

## Propuesta: Clínica

Aplicación web para administrar la asignación de **turnos, pacientes y médicos** de una clínica médica.

- Médicos asociados a una o más especialidades y a un turno de trabajo.
- Alta de turnos con sugerencia de horarios/médicos según especialidad (slots de 1 hora).
- Turnos con modelo de estados (Nuevo, Reprogramado, Cancelado, No Asistió, Cerrado): se reprograman o cancelan, nunca se eliminan.
- Confirmación de turno por email al paciente.
- Seguridad y perfiles: **Administrador**, **Recepcionista** y **Médico**.
